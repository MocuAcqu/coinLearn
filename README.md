# 算錢學習網站
這是一個幫助我朋友教導小孩子學習算錢的學習輔助工具，其中使用到的卡通圖片是希望提升該為孩子的喜好，可自行更換成不同圖片。

目前版本: V2.1

更新時間:2025/07/06

# 功能介紹
## 分類一: 錢幣算法學習
### 模式一：判斷錢幣
- 教學目標：練習判斷錢幣與算錢幣的價值金額。
- 怎麼玩：老師可以自由設定畫面中出現的錢幣組合和數量。學生需要觀察畫面，並透過數字鍵盤輸入正確的總金額。
- 提示功能：遇到困難時，可以點擊「💡提示」按鈕，系統會用循序漸進的方式提問（例如：「有多少個10元呢？」），引導孩子獨立思考，而非直接給予答案。
### 模式二：判斷金額
- 教學目標：練習湊錢與倍數概念，判斷錢幣之價值。
- 怎麼玩：老師設定一個目標金額（例如：60元），並指定學生只能使用某一種錢幣（例如：10元硬幣）或多種錢幣。學生需要點擊足夠數量錢幣來湊齊目標金額。
- 特殊功能：老師可以決定是否要顯示「目前總計」的金額，增加挑戰難度。當只指定一種錢幣時，同樣會出現引導式的提示，幫助學生理解除法概念。

## 分類三: 其他學習
### 模式一：錢幣配對
   - 隨機請小朋友選出對應金額的錢幣。
   
### 模式二：湊出金額
   - 隨機從1-1200元指定一個金額，讓小朋友選擇錢幣、點擊到對應數量，達到符合金額。
   
### 模式三：情境購物
   - 隨機給一張圖片，圖片可能是商品與價格，或是價目表，會根據圖片隨機出題，小朋友需要判斷商品金額，選擇錢幣、點擊到對應數量，達到符合價格。

### 模式四：小小商店
   - 老師可以設定商品名稱、價格與數量，並限制小朋友可以使用的硬幣種類與數量，讓小朋友經過計算後，選擇有限錢幣、點擊到對應數量，達到符合金額。
